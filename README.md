# Captura releases

Signed and notarized builds of **Captura**, a native macOS app for screenshots, recordings and annotations.

- **Download:** [latest release](https://github.com/Token-Dev-Co/captura-releases/releases/latest) → open `Captura-X.Y.Z.dmg` and drag Captura into Applications.
- **Requirements:** macOS 14 or later.
- **Updates:** Captura checks this repository and installs new versions from Settings → General → Updates.
- **Website:** https://captura-app-df.web.app

Each release ships `Captura-X.Y.Z.dmg` and a `Captura-X.Y.Z.dmg.sha256` checksum. Verify with `shasum -a 256 -c Captura-X.Y.Z.dmg.sha256`.

The source code is private; this repository only hosts release builds.
